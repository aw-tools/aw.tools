Get started

aw needs git, garden 2.6 or later, and dprint to keep work files tidy. Homebrew installs garden with aw.

{# the commands go through Markdown so they are highlighted like every other code block #}

  1. Install the tool.

    {% filter markdown | safe %} ```sh brew install aw-tools/tap/aw-cli ``` {% endfilter %}

  2. Create a workspace and go into it.

    {% filter markdown | safe %} ```sh aw init myproject.workspace cd myproject.workspace ``` {% endfilter %}

  3. Clone each repository you work on, then adopt it.

    {% filter markdown | safe %} ```sh git clone git@github.com:you/myrepo.git aw adopt myrepo ``` {% endfilter %}

  4. Bootstrap.

    {% filter markdown | safe %} ```sh aw bootstrap ``` {% endfilter %}

If something fails, aw doctor says what is missing. Chapter 3 covers other ways to install and the first session.
