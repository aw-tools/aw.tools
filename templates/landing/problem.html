The problem

  1. 01

    A session ends when its context fills, the terminal closes or you change machine.

  2. 02

    What carries over depends on the tool. Some agents keep notes in your home directory on that machine. Others keep nothing but an instruction file.

  3. 03

    Your agents' instructions and skills sit in per-tool folders, so a new machine or a new agent starts without them.

  4. 04

    The code repository holds the code, not the work around it. And work often spans several repositories.
