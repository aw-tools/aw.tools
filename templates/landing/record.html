What the record holds

A directory named context/ holds five kinds of record.

  • STATE.mdThe state file

    What is live, what is next, what is blocked. Every session reads it first.

  • DECISIONS.mdThe decision register

    Each decision with a number and a reason. Entries are added and never changed.

  • FINDINGS.mdThe findings file

    Verified facts about the environment.

  • NOTES.mdThe notes file

    Friction and observations not yet routed anywhere.

  • engagements/One directory per engagement

    A piece of work with a start and an end: its plan, and a ledger of what ran and what it showed.
